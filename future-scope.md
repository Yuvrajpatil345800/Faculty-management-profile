# Future Scope

- **Email notifications** — wire up a transactional email provider (SendGrid/Nodemailer)
  using the notification-ready structure already in place, to alert faculty when a
  certificate is approved/rejected or their profile is verified.
- **Two-factor authentication** for admin accounts.
- **Bulk faculty import** via CSV upload for institution onboarding.
- **Faculty-to-faculty directory search** with public profile pages.
- **Automated resume/CV parsing** to pre-fill publications and education.
- **Integration with ORCID / Google Scholar** to auto-sync publication records.
- **Audit logs** for admin actions (who verified/edited/deleted what and when).
- **Multi-tenant support** for managing multiple institutions from one deployment.
- **Mobile app** (React Native) reusing the existing REST API.
- **Advanced analytics** — publication trends over time, department comparison reports,
  exportable PDF analytics summaries.
- **Granular roles** (e.g., Department HOD role with department-scoped admin rights).
